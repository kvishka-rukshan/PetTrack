# PetTrack — Expo SDK 58 

Student Number: PE/2022/039

Multiple-pet care tracker built with Expo SDK 58, React Native 0.88.1 and React 19.3.0.

## Features
- Multiple pet profiles: dogs, cats, birds, rabbits and other pets
- Pet breed, age, weight and notes
- Health records for vaccinations, medication, check-ups and allergies
- Care reminders for feeding, medication, exercise, grooming and vet visits
- Local scheduled notifications on supported native devices
- Mark reminders as complete
- Local persistence with AsyncStorage

## Setup
1. Extract the ZIP and open this folder in VS Code.
2. Use Node.js 22.13 or newer (`node -v`).
3. Run `npm install`.
4. Run `npx expo install --fix` to align SDK module versions.
5. Run `npx expo-doctor`.
6. Run `npx expo start`.

## Expo Go
Use an Expo Go version compatible with SDK 58 or a development build. If your installed Expo Go does not support SDK 58, use a development build or switch to SDK 57 temporarily.

## Data
The starter stores pet profiles, health records and reminders locally on the device. There is no account system or cloud sync.
